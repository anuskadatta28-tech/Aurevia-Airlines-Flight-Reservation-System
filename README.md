# Aurevia-Airlines-Flight-Reservation-System
A Flight Reservation System developed to manage flight details and passenger bookings. This project provides two implementations: a **C++ Console-Based Version** and a **Web-Based Version**.

## Project Overview
Aurevia Airlines is designed to simplify basic flight management and reservation operations. It allows employees to manage flights and passengers to search, book, and cancel tickets.

## Features
### Passenger Module
- Search for available flights.
- Book flight tickets.
- Cancel existing bookings.
- View flight details.

### Employee Module
- Add new flights.
- Delete flights.
- Display available flights.
- Manage flight information.

## Technologies Used

## How to Run
### C++ Version
1. Open `CPP-Version/main.cpp` in a C++ IDE.
2. Compile the program using a C++ compiler.
3. Run the generated executable.

### Web Version
1. Open the `Web-Version` folder.
2. Open `index.html` in any web browser.
3. Select Passenger or Employee to explore the features.
